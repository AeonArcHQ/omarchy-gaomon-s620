# Agents

## Agent skills

### Issue tracker

GitHub Issues in AeonArcHQ/omarchy-gaomon-s620, through the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default roles, each label named after its role. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Bar entry

Before changing the bar entry, read `/usr/share/omarchy/shell/plugins/bar/README.md` ("Icon geometry") and match the shell's own widget for the same job (clicks, label, settings): for a battery, `/usr/share/omarchy/shell/plugins/panels/power/Panel.qml`.
